# Runners Feed Product Design System

Runners Feed is a dark, performance-oriented analysis interface. It uses an
acid-lime signal color, square geometry, thin dividers, and compact Korean copy
to make technical processing feel direct rather than decorative.

## Sources

- `frontend/styles.css`: canonical color, spacing, border, typography, motion,
  and responsive rules.
- `frontend/app/page.tsx`: canonical component structure, labels, statuses, and
  Korean product voice.

## Files

- `tokens/colors_and_type.css`: reusable raw and semantic design tokens.
- `brand/voice-and-tone.md`: product copy rules.
- `brand/style-notes.md`: layout, component, and interaction rules.
- `SKILL.md`: portable usage guidance for future product UI work.

The production frontend remains the source of truth. Update this system when
the product styles intentionally change.
